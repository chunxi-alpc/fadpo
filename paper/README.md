# Manuscript sources

This directory contains the latest manuscript and revision materials selected from the local revision workspace.

- `main.tex`: current manuscript source.
- `main_review_marked.tex`: marked manuscript source for revision review.
- `response_letter2.tex`: current detailed response letter.
- `sample-base.bib`: bibliography used by the manuscript and response letter.
- `cas-sc.cls`, `cas-common.sty`, `cas-model2-names.bst`: LaTeX class, style, and bibliography style files.
- `overview.png`, `sensitivity.pdf`, `win_rate.pdf`: figures referenced by the manuscript.

Build artifacts, intermediate files, historical drafts, and private review/audit data are not included.
