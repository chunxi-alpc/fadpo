# Public experiment protocols

This directory contains the protocol-level materials needed to understand the main attribution and validation checks reported in the paper.

Included materials cover:

- normalization and component-interaction ablations;
- retained-pool and dataset-bias analysis;
- ARU parser validation;
- NLI false-positive analysis;
- computational-cost measurement;
- paired confidence-interval analysis.

Raw clinical annotations, patient-containing records, private audit keys, generated corpora, model outputs, and run logs are excluded. Paths in the public protocols are illustrative; provide authorized inputs through command-line arguments or private runtime directories.
